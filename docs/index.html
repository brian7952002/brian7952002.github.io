/04

Method

I have zero tolerance for manual, repetitive work. Not because I'm lazy, but because tedious work is usually a symptom, not a fact of life.

  1. 01

    Listen

    Hear the problem the way the person doing the work feels it.

  2. 02

    Find the real goal

    The actual goal, not just the stated task.

  3. 03

    Map the paths

    Systems, data flows, people and handoffs.

  4. 04

    Question the process

    Why it's done this way, not just how.

  5. 05

    Find root behaviors

    What's actually driving the manual work.

  6. 06

    Build a better path

    Integrate, automate, document, adopt.

"Systems thinking without empathy is just efficiency theater."
